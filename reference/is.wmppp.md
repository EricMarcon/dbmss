# Test whether an object is a weighted, marked, planar point pattern

Check whether its argument is an object of class "wmppp"
([`wmppp.object`](https://ericmarcon.github.io/dbmss/reference/wmppp.object.md)).

## Usage

``` r
is.wmppp(X)
```

## Arguments

- X:

  Any object

## Value

`TRUE` if `X` is a weighted, marked, planar point pattern, otherwise
`FALSE`.
